## 🚀 CÀI ĐẶT DỰ ÁN

Để chạy thử trang web trên máy cá nhân:

```bash
# 1. Cài đặt các thư viện cần thiết
npm install

# 2. Chạy ở chế độ phát triển
npm run dev

# 3. Đóng gói & khởi chạy máy chủ sản phẩm
npm run build
npm start
```
Trang web sẽ hoạt động tại `buitankhang.vercel.app`.
